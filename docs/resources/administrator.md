# panos_administrator (Resource)

Manages PAN-OS administrator accounts on Panorama. Administrators can be scoped to Panorama itself, or pushed via a template or template stack.

~> **Note:** Exactly one of `location.panorama`, `location.template`, or `location.template_stack` must be specified. Changing the location forces the resource to be recreated.

~> **Note:** The `password` attribute stores the administrator's hashed password. After import, the plaintext password is not retrievable from the device. You must set `password` to the plaintext value after import.

## Example Usage

```hcl
# Panorama superuser administrator
resource "panos_administrator" "superuser" {
  location = {
    panorama = {}
  }

  name     = "admin-superuser"
  password = "SecretP@ssword123"

  permissions = {
    role_based = {
      superuser = true
    }
  }
}

# Custom-role administrator via template
resource "panos_administrator" "custom_admin" {
  location = {
    template = {
      panorama_device = "localhost.localdomain"
      name            = "my-template"
    }
  }

  name                   = "custom-admin"
  password               = "AnotherSecret123"
  authentication_profile = "LDAP-Auth"

  permissions = {
    role_based = {
      custom = {
        profile = "custom-admin-role"
      }
    }
  }
}

# Read-only device administrator via template stack
resource "panos_administrator" "readonly" {
  location = {
    template_stack = {
      panorama_device = "localhost.localdomain"
      name            = "my-template-stack"
    }
  }

  name        = "readonly-admin"
  public_key  = "ssh-rsa AAAA..."

  permissions = {
    role_based = {
      devicereader = true
    }
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# An administrator can be imported by providing the following base64 encoded object as the ID.

# Panorama location:
terraform import panos_administrator.example $(echo '{"location":{"panorama":{}},"name":"example-admin"}' | base64)

# Template location:
terraform import panos_administrator.example $(echo '{"location":{"template":{"name":"my-template","panorama_device":"localhost.localdomain"}},"name":"example-admin"}' | base64)

# Template stack location:
terraform import panos_administrator.example $(echo '{"location":{"template_stack":{"name":"my-template-stack","panorama_device":"localhost.localdomain"}},"name":"example-admin"}' | base64)
```

~> **After import:** The `password` attribute will contain the placeholder value `[PLAINTEXT-VALUE-MISSING]` since the provider cannot decrypt hashed passwords from the device. Update your configuration with the actual plaintext password before running `terraform apply`.
