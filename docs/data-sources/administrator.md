# panos_administrator (Data Source)

Use this data source to read the configuration of a PAN-OS administrator account on Panorama.

## Example Usage

```hcl
# Read a Panorama administrator
data "panos_administrator" "example" {
  location = {
    panorama = {}
  }
  name = "admin"
}

# Read an administrator from a template
data "panos_administrator" "template_admin" {
  location = {
    template = {
      panorama_device = "localhost.localdomain"
      name            = "my-template"
    }
  }
  name = "template-admin"
}

output "admin_auth_profile" {
  value = data.panos_administrator.example.authentication_profile
}
```
